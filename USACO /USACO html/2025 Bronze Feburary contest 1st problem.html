The canvas is four copies one quadrant, reflected

FJ paints the top-right quadrant of an even N × N canvas, then reflects it across the vertical and horizontal center lines.

A canvas is valid when that reflection reproduces the whole grid exactly. Every cell and its three mirror images hold the same value.

Each update flips one cell. After every update, output the minimum number of flips needed to make the canvas valid.

N ≤ 2000 U ≤ 2·10⁵ N is even

Reflect (r, c) and three partners come with it:

(r, c) · (r, N−1−c)
(N−1−r, c) · (N−1−r, N−1−c)

Because N is even, no cell is its own twin. The canvas splits into exactly N²/4 groups of four: 16 groups at N = 8, and one million at N = 2000.

Any of the four cells gives the same orbit.

Orbits never talk independent decisions

orbit — painted k 0 cost 0 total 0

Click a cell to flip it; the yellow ring marks its orbit.

Call each group of four an orbit. Reflections map every orbit onto itself, never onto a different one.

That makes the orbits independent. Deciding that one orbit ends up all painted cannot force any choice in another orbit.

So the cheapest valid canvas is the sum of each orbit's cheapest repair, taken separately. There is no trade to make between them.

An orbit never needs information from another orbit, so minimizing each one separately gives the global minimum.

Two ways to fix one orbit take the cheaper

A light square is one painted cell.

An orbit with k painted cells has 4 − k blank cells. A valid canvas needs all four equal, and there are only two ways to get there.

Paint the blanks: 4 − k flips, ending all #.
Erase the paint: k flips, ending all .

cost(k) = min(k, 4 − k)

Its values are 0, 1, 2, 1, 0. An orbit never costs more than 2, because one of the two choices is always available for at most half the cells.

With N²/4 orbits, the answer never exceeds N²/2 — 2,000,000 at the largest N.

The four cells are drawn as they sit around the center: two above, two below.

An update flips a single cell, and that cell belongs to exactly one orbit. Only that orbit's count k changes.

Remove its old cost, apply the flip, add the new cost:

answer += cost(k′) − cost(k)

Recounting the whole canvas after every update would cost O(N²) per update. Looking at one orbit instead makes each update constant time.

time
O(N² + U)
memory
O(N²)

Putting it together

answer = Σ min(k, 4 − k)  over all N²/4 orbits

① Count

For every painted cell, find its canonical orbit (min(r, N−1−r), min(c, N−1−c)) and increment that count.

② Sum

Add min(k, 4−k) over all N²/4 orbit counts. That is the answer before any updates.

③ Update

Subtract the old cost, flip the cell, adjust the count, add the new cost. One orbit per update.

answer += cost(k′) − cost(k)

The canonical index works from any of the four cells, so one array of size h × h, where h = N/2, is enough.

At the limits N = 2000 · U = 200,000

4,000,000cells to count
1,000,000orbits in the canvas
200,000updates to apply

The budget

O(N² + U) is about 4.2 million steps. Recounting after every update would be O(N² · U), about 8·10¹¹ cell visits — far too slow.

The fit

The answer is at most N²/2 = 2,000,000, so a 32-bit integer is enough. The grid and the orbit counts both fit easily in memory.

Summary

  

    
① Four cells, one value
Reflections pair every cell with three twins. A valid canvas gives each orbit one value.

    
② Take the cheaper fix
An orbit with k painted cells costs min(k, 4−k), never more than 2.

    
③ Repair one orbit
Each update touches one orbit, so subtract the old cost and add the new one.
