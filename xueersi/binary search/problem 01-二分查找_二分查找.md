# 1.1 二分查找

## 题目描述

给出一个数列 `a₁, a₂, ..., aₙ`。之后给出 `Q` 个数 `b₁, ..., b_Q`，你需要对每个数 `b_j`，回答 `b_j` 是否在数列 `a` 中。

## 输入格式

- 第 1 行，两个正整数 `n, Q`
- 第 2 行，`n` 个正整数 `a₁, a₂, ..., aₙ`
- 第 3 行，`Q` 个正整数 `b₁, ..., b_Q`

## 输出格式

输出 `Q` 行，第 `j` 行代表 `b_j` 是否在数列 `a` 中。

如果在，输出 `Yes`；如果不在，输出 `No`。

## 样例

### 样例 #1

**输入:**

```
5 3
6 5 1000000009 1 4008
7777 5 4008
```

**输出:**

```
No
Yes
Yes
```

## 数据说明

- `1 ≤ n, Q ≤ 10^5`
- `1 ≤ a_i, b_j ≤ 10^18`
