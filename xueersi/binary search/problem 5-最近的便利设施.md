# 最近的便利设施

## 题目描述

在一条东西向的城市主干道上，分布着 $A$ 家便利店和 $B$ 家药店。以道路最西端为坐标原点，第 $i$ 家便利店位于坐标 $s_i$ 处，第 $j$ 家药店位于坐标 $t_j$ 处。

市民经常需要查询距离自己最近的便利设施有多远。你需要回答以下 $Q$ 个询问：

- 第 $k$ 次询问：市民在坐标 $x_k$ 处，请问距离他最近的便利设施（便利店或药店）有多远？

## 输入描述

- 第 1 行：$3$ 个正整数 $A, B, Q$，分别表示便利店数量、药店数量、询问次数。
- 第 2 行：$A$ 个正整数 $s_1, s_2, \cdots, s_A$，表示各便利店坐标。
- 第 3 行：$B$ 个正整数 $t_1, t_2, \cdots, t_B$，表示各药店坐标。
- 接下来 $Q$ 行：每行 $1$ 个正整数 $x_k$，表示市民位置。

## 输出描述

输出 $Q$ 行，第 $k$ 行输出第 $k$ 次询问的答案，即最近距离。

## 样例 1

输入：

```
2 2 3
10 30
20 40
20
15
50
```

输出：

```
0
5
10
```

## 样例 2

输入：

```
3 4 5
100 300 600
200 400 700 900
250
100
500
700
50
```

输出：

```
50
0
100
0
50
```

## 样例 3

输入：

```
3 2 4
100 500 1000
300 700
100
600
1200
250
```

输出：

```
0
100
200
50
```

## 提示

**样例 1 说明：**

有 $2$ 家便利店（坐标 $10, 30$）和 $2$ 家药店（坐标 $20, 40$）。

- 第 1 问：市民在 $20$，药店恰好在 $20$，距离为 $0$。
- 第 2 问：市民在 $15$，最近的是便利店 $10$ 或药店 $20$，距离都是 $5$。
- 第 3 问：市民在 $50$，最近的是药店 $40$，距离为 $10$。

**样例 2 说明：**

- 第 1 问：市民在 $250$，最近的是药店 $200$ 或便利店 $300$，距离都是 $50$。
- 第 2 问：市民在 $100$，便利店恰好在 $100$，距离为 $0$。
- 第 3 问：市民在 $500$，最近的是药店 $400$ 或便利店 $600$，距离都是 $100$。
- 第 4 问：市民在 $700$，药店恰好在 $700$，距离为 $0$。
- 第 5 问：市民在 $50$，最近的是便利店 $100$，距离为 $50$。

**样例 3 说明：**

- 第 1 问：市民在 $100$，便利店恰好在 $100$，距离为 $0$。
- 第 2 问：市民在 $600$，最近的是便利店 $500$ 或药店 $700$，距离都是 $100$。
- 第 3 问：市民在 $1200$，最近的是便利店 $1000$，距离为 $200$。
- 第 4 问：市民在 $250$，最近的是药店 $300$，距离为 $50$。

**数据范围：**

- $1 \le A, B, Q \le 10^5$
- $1 \le s_i, t_j, x_k \le 10^{10}$
- 所有 $s_i, t_j$ 都互不相同。
