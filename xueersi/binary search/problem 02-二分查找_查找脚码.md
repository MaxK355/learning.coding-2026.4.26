# 1.2 二分查找 - 查找脚码

## 题目描述

给出一个数列 `a₁, a₂, ..., aₙ`。之后给出 `Q` 个数 `d₁, ..., d_Q`，你需要对每个数 `d_j`，回答是否存在一个 `i`，使得 `a_i = i + d_j`。

## 输入格式

- 第 1 行，两个正整数 `n, Q`
- 第 2 行，`n` 个正整数 `a₁, a₂, ..., aₙ`
- 第 3 行，`Q` 个正整数 `d₁, ..., d_Q`

## 输出格式

输出 `Q` 行，第 `j` 行代表对每个数 `d_j`，是否存在一个 `i`，使得 `a_i = i + d_j`。

如果存在，输出 `Yes`；如果不存在，输出 `No`。

## 样例

### 样例 #1

**输入:**

```
5 3
6 5 1000000009 1 4008
5 4008 -3
```

**输出:**

```
Yes
No
Yes
```

### 样例说明

- 对于 `d₁ = 5`，存在 `i = 1` 使得 `a₁ = 1 + 5`
- 对于 `d₂ = 4008`，不存在 `i` 使得 `a_i = i + 4008`
- 对于 `d₃ = −3`，存在 `i = 4` 使得 `a₄ = 4 + (−3)`

## 数据说明

- `1 ≤ n, Q ≤ 10^5`
- `-10^18 ≤ a_i, d_j ≤ 10^18`
