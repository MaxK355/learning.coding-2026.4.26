# 快排求中位数

## 题目描述

你会得到 $n$ 个数，求出其中位数并输出。

本题中，中位数的定义是第 $\lceil n/2 \rceil$ 小的数。例如 $n = 6$ 时中位数是从小到大第 $3$ 个数。

## 输入描述

第一行是整数 $n$，表示数的个数；

第二行 $n$ 个整数。

## 输出描述

输出一个整数，为中位数。

## 样例 1

### 输入

```
4
3 6 4 5
```

### 输出

```
4
```

## 样例 2

### 输入

```
3
1 2 3
```

### 输出

```
2
```

## 提示

$1 \le n \le 5 \times 10^6$；

$1 \le$ 每个输入的整数 $\le 2^{31} - 1$。
