# 题目描述

田忌又与齐威王进行赛马了，这次他们两都准备了好多马，且每匹马的"战斗力"都不同。已知田忌有 $n$ 匹马，"战斗力" 分别为 $a_1, \dots, a_n$，齐威王有 $m$ 匹马，战斗力分别为 $b_1, \dots, b_m$。

现在田忌与齐威王都想知道自己的每批马，能够战胜对面多少匹马？请你帮他们计算。

## 输入描述

第一行两个正整数 $n, m$。

第二行 $n$ 个正整数 $a_1, \dots, a_n$。

第三行 $m$ 个正整数 $b_1, \dots, b_m$。

## 输出描述

第一行 $n$ 个整数，依次表示田忌每匹马能战胜对面马的数量。

第二行 $m$ 个整数，依次表示齐威王每匹马能战胜对面马的数量。

## 样例1

### 输入

```
4 5
2 4 6 8
1 3 5 7 9
```

### 输出

```
1 2 3 4
0 1 2 3 4
```

## 样例2

### 输入

```
6 6
7 348 45 13 123 4
84 756 47 12 8 29
```

### 输出

```
0 5 3 2 5 0
4 6 4 2 2 3
```

## 提示

对于 $100\%$ 数据：

$1 \le n, m \le 10^5$，$1 \le a_i, b_j \le 10^9$，保证每匹马的"战斗力"是唯一的。
