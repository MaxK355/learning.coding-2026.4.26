# 题目描述

考虑如下的递推函数 `F`：

- `F(n, 0) = 0`  `(n > 0)`
- `F(n, n) = 1`  `(n ≥ 0)`
- `F(n, k) = 0`  `(k > n)`
- `F(n, k) = F(n−1, k−1) + k·F(n−1, k)`  `(1 ≤ k < n)`

输入 `n, k`，求 `F(n, k)` 除以 `10^9 + 7` 的余数，用递归函数实现。

## 输入格式

两个整数 `n, k`，用空格分隔。

## 输出格式

输出 `F(n, k)` 的值除以 `10^9 + 7` 的余数。

## 输入样例 #1

```
3 2
```

## 输出样例 #1

```
3
```

## 数据说明

`0 ≤ k ≤ n ≤ 1000`
