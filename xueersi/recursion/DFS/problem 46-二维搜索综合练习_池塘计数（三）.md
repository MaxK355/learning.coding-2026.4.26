# problem 46 - 二维搜索综合练习：池塘计数（三）

## 题目描述

下暴雨后，某矩形地面上出现了一些小池塘，Karl 可以在其中一个无水的网格上加水，当然他也可以不加，请问池塘数量最小可能是多少？

我们将矩形地面分为 $n \times m$ 个网格，每个网格与八方向相邻网格是相连的，如果相邻的网格上面都有水，那么它们应该属于同一个池塘。

## 输入描述

- 第一行两个正整数 $n, m$。
- 接下来 $n$ 行每行 $m$ 个字符，依次表示对应网格的情况，`*` 表示有水，`.` 表示无水。

## 输出描述

一个整数表示结果。

## 样例 1

**输入**

```text
3 4
**..
..**
*..*
```

**输出**

```text
1
```

## 样例 2

**输入**

```text
3 5
*...*
..*..
*...*
```

**输出**

```text
3
```

## 提示

对于 $50\%$ 数据：$1 \le n, m \le 10$。

对于 $100\%$ 数据：$1 \le n, m \le 500$。
