# problem 45 - 二维搜索综合练习：山的大小

## 题目描述

小猴特别喜欢爬山，在爬山的时候他就在研究山的大小，为了能够对旅程有一个安排，他想知道每个山的大小。

给定一个地图，为小猴想要旅行的区域，地图被分为 $n \times n$ 的网格，每个格子 $(i, j)$ 的高度 $w_{i,j}$ 是给定的。

若两个格子有公共边，那么它们就是相邻的格子，如与 $(i, j)$ 相邻的格子有 $(i-1, j)$、$(i, j-1)$、$(i, j+1)$、$(i+1, j)$。能够通过若干相邻格子到达的格子是连通的。

我们定义一个格子的集合 $S$ 为**山**当且仅当：

1. $S$ 的所有格子都有大于 $0$ 的高度；
2. $S$ 的所有格子都连通。

小猴将「山的面积」定义为山的格子个数；「山的大小」定义为山的所有格子的高度总和。你的任务是，对于给定的地图，回答小猴的询问，每个询问是「包含格子 $(i, j)$ 的山的面积和大小是什么？」。

## 输入描述

- 第一行包含两个正整数 $n, T$，表示地图的大小和询问的次数。
- 接下来一个 $n \times n$ 的矩阵，表示地图上每个格子的高度 $w$。
- 接下来 $T$ 行，每行两个数 $i, j$，表示询问「包含格子 $(i, j)$ 的山的面积和大小是什么？」

## 输出描述

输出 $T$ 行。

如果格子 $(i, j)$ 属于一个山，输出两个整数，表示山的面积和大小；如果格子 $(i, j)$ 不属于任何山，输出 $-1$。

## 样例 1

**输入**

```text
5 3
8 0 4 3 0
9 9 0 1 2
9 0 0 1 0
0 0 2 5 0
7 1 0 1 1
2 2
3 4
1 5
```

**输出**

```text
4 35
9 20
-1
```

## 提示

$$1 \le n, T \le 1000$$

$$0 \le w \le 1000$$
