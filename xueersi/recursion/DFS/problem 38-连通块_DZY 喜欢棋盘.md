# DZY 喜欢棋盘（连通块）

## 题目描述

DZY 喜欢在棋盘上玩。

他有一个 $n$ 行 $m$ 列的棋盘，棋盘上的格子分为好格和坏格，DZY 在每个好格上放一个黑或白的棋子，并保证同色棋子不相邻（两个格子相邻为它们存在共同的边）。

你要给出一个可行的摆法。

## 输入描述

输入共 $n+1$ 行：

- 第 $1$ 行，两个用空格隔开的整数 $n, m$，意义如题目描述。
- 第 $2 \sim n+1$ 行，每行一个 $m$ 长度的字符串，由 `.` 和 `-` 组成，这给出了整个棋盘的 $1 \sim n$ 行。`.` 表示这里是一个好格，`-` 则表示坏格。

## 输出描述

输出共 $n$ 行：

- 第 $1 \sim n$ 行，每行一个 $m$ 长度的字符串，由 `W`、`B` 和 `-` 组成，这是按要求放置完棋子的整个棋盘的 $1 \sim n$ 行。`W` 表示这里放了一个白色棋子，`B` 表示这里放了一个黑色棋子，`-` 则表示坏格。

请保证每个区域的最上一行的最左一个棋子是黑子。

## 样例 1

### 输入

```text
2 2
..
..
```

### 输出

```text
BW
WB
```

## 样例 2

### 输入

```text
3 3
.-.
---
--.
```

### 输出

```text
B-B
---
--B
```

## 提示

$1 \le n, m \le 100$。
