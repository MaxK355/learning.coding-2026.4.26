# 迷宫

## 题目描述

给定一个 n 行 m 列的迷宫，有些格子可以走，有些有障碍物不能到达。每步可以走到上下左右的格子中。请你判断，是否能从左上角走到右下角。如果能走到输出 YES，否则输出 NO。

## 输入描述

第一行有两个正整数 n 和 m，表示迷宫的行数和列数。

接下来 n 行为输入这个迷宫，每行为一个长度为 m 的字符串。第 i 行第 j 列的字符为 `*` 表示迷宫第 i 行第 j 列的格子有障碍物，为 `.` 表示没有障碍物。

## 输出描述

输出 YES 或 NO。

## 样例 1

**输入**

```text
3 3
.**
...
.*.
```

**输出**

```text
YES
```

## 提示

- 对于 100% 的数据，1 ≤ n, m ≤ 20。
