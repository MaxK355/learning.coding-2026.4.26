# 数数有几个湖（连通块）

## 题目描述

由于近期的降雨，雨水汇集在农民约翰的田地不同的地方。我们用一个 $N \times M$（$1 \le N \le 100, 1 \le M \le 100$）网格图表示。每个网格中有水（`W`）或是旱地（`.`）。一个网格与其周围的八个网格相连，而一组相连的网格视为一个湖。

约翰想弄清楚他的田地已经形成了多少湖。给出约翰田地的示意图，确定当中有多少湖。

## 输入描述

输入共 $2$ 行：

- 第 $1$ 行，$2$ 个空格隔开的整数：$N$ 和 $M$。
- 第 $2$ 行到第 $N+1$ 行，每行 $M$ 个字符，每个字符是 `W` 或 `.`，它们表示网格图中的一排。字符之间没有空格。

## 输出描述

输出共 $1$ 行：

- 第 $1$ 行：$1$ 个整数，湖的个数。

## 样例 1

### 输入

```text
10 12
W........WW.
.WWW.....WWW
....WW...WW.
.........WW.
.........W..
..W......W..
.W.W.....WW.
W.W.W.....W.
.W.W......W.
..W.......W.
```

### 输出

```text
3
```
