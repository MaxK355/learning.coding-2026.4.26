# 迷宫路径条数

## 题目描述

给定一个 n 行 m 列的迷宫，假设没有障碍物和陷阱。每步可以走到上下左右的格子中。请你判断，从输入的起点 S 到输入的终点 E 之间有多少条不同的路径。两条路径中至少存在一个不同的点称为不同的路径。

## 输入描述

第一行有两个正整数 n 和 m，表示迷宫的大小。

接下来 2 行，每行 2 个整数，表示起点行列坐标和终点行列坐标。

## 输出描述

输出从起点到终点的路径条数。

## 样例 1

**输入**

```text
3 2
1 1
3 2
```

**输出**

```text
4
```

## 提示

- 对于 100% 的数据，2 ≤ n, m ≤ 20，1 ≤ n*m ≤ 40。
