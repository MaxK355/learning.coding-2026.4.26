# 题目描述

## 【题目描述】

房间里放着 n 块奶酪。一只小老鼠要把它们都吃掉，问至少要跑多少距离？老鼠一开始在 (0,0) 点处。

## 【输入格式】

- 第一行一个数 n (n <= 12)
- 接下来每行 2 个实数，表示第 i 块奶酪的坐标

两点之间的距离公式：

$$d=\sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}$$

## 【输出格式】

一个数，表示要跑的最少距离，四舍五入保留 2 位小数。

## 【输入样例 #1】

```
4
1 1
1 -1
-1 1
-1 -1
```

## 【输出样例 #1】

```
7.41
```

## 【数据范围】

对于全部的测试点，保证 1 <= n <= 12，|x_i|, |y_i| <= 200，小数点后最多有 3 位数字。
