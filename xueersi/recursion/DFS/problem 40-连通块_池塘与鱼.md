# 池塘与鱼（连通块）

## 题目描述

我们将矩形地面分为 $n \times m$ 个网格，每个网格与上下左右相邻网格是相连的，如果相邻的网格上面都有水，那么它们应该属于同一个池塘。

在这些池塘中有一些小鱼，如果两条小鱼在同一个池塘中，那我们就说它们是一对好朋友。

给定两条小鱼所在的位置，请你判断一下它们是不是好朋友？

## 输入描述

- 第 $1$ 行，两个正整数 $n, m$。
- 第 $2 \sim n+1$ 行，每行 $m$ 个字符，依次表示对应网格的情况，`*` 表示有水，`.` 表示无水。
- 第 $n+2$ 行，一个正整数 $Q$，表示询问次数。
- 之后的 $Q$ 行，每行 $4$ 个正整数 $x_1, y_1, x_2, y_2$。$(x_1, y_1)$ 表示第一条小鱼所在位置，$(x_2, y_2)$ 表示第二条小鱼所在的位置。

## 输出描述

共 $Q$ 行，每行输出一个结果。如果两条小鱼在同一个池塘，那么输出 `Yes`，否则输出 `No`。

## 样例 1

### 输入

```text
3 4
**..
..**
*..*
2
1 1 1 2
1 1 2 3
```

### 输出

```text
Yes
No
```

## 样例 2

### 输入

```text
3 3
*.*
.*.
*.*
1
1 1 3 3
```

### 输出

```text
No
```

## 提示

- 对于 $30\%$ 数据：$1 \le x_1, x_2 \le n \le 10$，$1 \le y_1, y_2 \le m \le 10$，$1 \le Q \le 10$；
- 另有 $10\%$ 数据：$Q = 1$；
- 对于 $100\%$ 数据：$1 \le x_1, x_2 \le n \le 500$，$1 \le y_1, y_2 \le m \le 500$，$1 \le Q \le 10^5$。
