# 题目描述

餐厅里有 $n$ 种菜，第 $i$ 种卖 $p_i$ 元，每种菜最多只能点一份。现在打算花光 $m$ 元。请问有几种点菜方式？

# 输入描述

输入共 $2$ 行：

- 第 $1$ 行，$2$ 个正整数 $n$，$m$；
- 第 $2$ 行，$n$ 个正整数 $p_1$，$p_2$，…，$p_n$。

# 输出描述

输出共 $1$ 行：

- 第 $1$ 行，有多少种花费 $m$ 元的点菜方式。

# 样例1

## 输入

```
4 5
1 2 3 4
```

## 输出

```
2
```

# 提示

$n \le 10$；$m \le 1000$；$p_i \le 100$；$p_i$ 各不相同。
