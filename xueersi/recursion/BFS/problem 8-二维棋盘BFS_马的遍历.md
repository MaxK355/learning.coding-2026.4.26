# 马的遍历

## 题目描述

有一个 n∗m 的棋盘（1 < n, m ≤ 400），在某个点上有一个马，要求你计算出马到达棋盘上任意一个点最少要走几步。

## 输入描述

一行四个数据，棋盘的大小和马的坐标。

## 输出描述

一个 n∗m 的矩阵，代表马到达某个点最少要走几步（左对齐，宽 5 格，不能到达则输出 −1）。

## 样例 1

**输入**

```text
3 3 1 1
```

**输出**

```text
0    3    2
3    -1   1
2    1    4
```

## 提示

- 可以使用 `"%-5d"` 输出左对齐宽 5 格的格式。
- 数据范围：1 < n, m ≤ 400。
