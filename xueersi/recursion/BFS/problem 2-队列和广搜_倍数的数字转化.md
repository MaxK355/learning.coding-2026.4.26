# 倍数的数字转化

## 题目描述

LCR 和小 A 在玩这样一个游戏。LCR 在纸上写了一个数字 $n$，紧接着又在另一张纸上写了一个数字 $1$，接下来小 A 可以在这个 $1$ 的后面随意添加一些 $0$ 或者 $1$，从而得到一个新的数字，现在 LCR 希望小 A 得到的这个新的数字是 $n$ 的倍数。由于小 A 很懒，所以他希望自己添加的 $0$ 和 $1$ 的个数的总和最小（这样他动笔次数就最少）。

你需要帮助小 A 算出他最少需要在初始的 $1$ 后面填加多少个数码才能使得这个新数字是 $n$ 的倍数，如果无论添加多少个数码都不能是 $n$ 的倍数，那么你需要输出 $-1$。

## 输入描述

一行一个正整数 $n$。

## 输出描述

共一行，一个数字表示小 A 最少需要添加多少个数码。

## 样例 1

**输入**

```text
2
```

**输出**

```text
1
```

## 样例 2

**输入**

```text
6
```

**输出**

```text
3
```

## 样例 3

**输入**

```text
84447
```

**输出**

```text
21
```

## 提示

你可以认为小 A 刚开始的数码是 $x = 1$，接下来他有两种变化数码的方式，要么把 $x$ 变为 $x \times 10 + 1$，要么把 $x$ 变为 $x \times 10$。

对于样例 2，$1110$ 就是 $6$ 的倍数，可以看作是在 $1$ 的后面添了 $3$ 个数码，可以证明，这就是添数码最少的方案。

$$2 \le n \le 2 \times 10^5$$

所有输入均为整数。
