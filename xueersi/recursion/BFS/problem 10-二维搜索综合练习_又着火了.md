# problem 44 - 二维搜索综合练习：又着火了

## 题目描述

一个街道被分成 $n \times m$ 的网格。

目前有 $k$ 个格子已经起火，每个起火的格子每个单位时间都会向上下左右延伸，延伸出来的新的格子也会起火。

问哪些格子起火的时间最晚。

## 输入描述

- 第 1 行包含 2 个整数 $n, m$。
- 第 2 行包含 1 个整数 $k$，初始起火格子个数。
- 接下来 $k$ 行，每行 2 个整数 $x_i, y_i$，表示初始起火格子位置。

## 输出描述

每行一个，输出所有最晚起火的格子。

输出顺序按行坐标从小到大，相同行的按列坐标从小到大。

## 样例 1

**输入**

```text
3 3
1
3 1
```

**输出**

```text
1 3
```

## 样例 2

**输入**

```text
3 3
1
2 2
```

**输出**

```text
1 1
1 3
3 1
3 3
```

## 样例 3

**输入**

```text
3 3
2
1 1
3 3
```

**输出**

```text
1 3
2 2
3 1
```

**数据范围**

$$1 \le n, m \le 2000$$

$$1 \le k \le 10$$

$$1 \le x_i \le n, \quad 1 \le y_i \le m$$
