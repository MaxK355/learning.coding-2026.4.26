# 题目描述

【题目描述】

写一个递归函数，枚举 $n$ 个数 $x_1, \cdots, x_n$ 的所有排列方式（全排列枚举）。若两种排列方法中前 $k-1$ 个数相同，则第 $k$ 个数序号更小的在前。例如对 $n=3$，$X=\{100, 20, 3\}$，应该按如下顺序给出结果：

- `{100, 20, 3}`
- `{100, 3, 20}`
- `{20, 100, 3}`
- `{20, 3, 100}`
- `{3, 100, 20}`
- `{3, 20, 100}`

【输入格式】

第一行一个正整数 $n$。

第二行 $n$ 个正整数，$x_1, \cdots, x_n$。

【输出格式】

$n!$ 行，每行一个排列，按题目要求顺序。

【输入样例#1】

```
3
100 20 3
```

【输出样例#1】

```
100 20 3
100 3 20
20 100 3
20 3 100
3 100 20
3 20 100
```

【数据说明】

$1 \le n \le 8$；$1 \le x_i \le 10^7$。
