# 题目描述

【题目描述】
直线上依次有 $1 \sim n$ 号位置，相邻位置距离为 $1$，部分位置上有百合花，只有这些位置青蛙可以站上去。一只青蛙在 $1$ 号位置，而它的家在 $n$ 号位置，他每次可以跳 $1 \sim d$ 的距离。你要计算青蛙至少跳几次可以到家。

【输入格式】
输入共 2 行：
第 1 行，两个用空格隔开的整数 $n, d$，意义如题目描述。
第 2 行，$n$ 长度的由 0,1 组成的字符串，依次表示 $1 \sim n$ 号位置是否有百合花，1 表示有，0 表示无。

【输出格式】
输出共 1 行：
第 1 行，1 个整数，为青蛙到家至少需要跳的次数。如果它不可能回家则输出 $-1$。

【输入样例#1】
```
12 3
101111100101
```

【输出样例#1】
```
4
```

【数据说明】
$2 \le n \le 100;\ 1 \le d \le n - 1$
