# 验证八皇后

## 题目描述

对一个如下的 $8 \times 8$ 的国际象棋棋盘，有八个皇后被放置在棋盘上，使得每行、每列和每条斜线上都至多只有一个皇后，这就是著名的八皇后问题，下图是其中一个解。

类似地我们可以定义 $n$ 皇后问题：$n \times n$ 的国际象棋棋盘，有 $n$ 个皇后被放置在棋盘上，使得每行、每列和每条斜线上都至多只有一个皇后。容易发现每行一定会恰好有一个皇后，我们用 $a_i$ 表示第 $i$ 行的皇后在第 $a_i$ 列。例如图中的解可以表示成 $\{1,5,8,6,3,7,2,4\}$。给出数组 $a_1, a_2, \cdots, a_n$，验证这组排列是否是 $n$ 皇后的一个解。

## 输入描述

输入共 $2$ 行：

- 第 1 行，一个正整数 $n$
- 第 2 行，$n$ 个正整数，数组 $a_1, a_2, \cdots, a_n$

## 输出描述

输出共 $1$ 行：

- 如果是一个解，则输出 `Yes`，否则输出 `No`。

## 样例 1

### 输入

```
8
1 5 8 6 3 7 2 4
```

### 输出

```
Yes
```

## 提示

$$
1 \le n \le 10
$$

$$
1 \le a_i \le n
$$
