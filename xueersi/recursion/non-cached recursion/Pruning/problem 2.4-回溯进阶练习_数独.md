# 数独

## 题目描述

"数独"是一个非常流行的智力游戏。游戏中你会得到一个 $9 \times 9$ 的表格，其中一些格子中已经填写了一些 $1 \sim 9$ 的数字，你需要在剩下的格子中填上 $1 \sim 9$ 的数字，使得每行、每列和每个 $3 \times 3$ 的"宫"中，$1 \sim 9$ 的数字各出现恰好一次。如下图是一个正确完成的数独，可以看出其中每行、每列和每个"宫"（图中每个粗线隔开的 $3 \times 3$ 区域就是"宫"），$1 \sim 9$ 的数字都各出现恰好一次。



## 输入描述

输入共 $9$ 行，每行 $9$ 个用空格隔开的一位整数，这些数展示了需要填写完成的数独表格。保证每个数都是 $0 \sim 9$ 范围内的正整数，其中 $0$ 表示需要填写。注意一个正确的数独题的解是存在且唯一的，本题的数据也保证这一点。

## 输出描述

输出共 $9$ 行，每行 $9$ 个用空格隔开的整数，这些数展示了整个填写完成的数独表格。每个数应都是 $1 \sim 9$ 范围内的正整数。

## 样例 1

### 输入

```
2 0 0 0 8 0 3 0 0
0 6 0 0 7 0 0 8 4
0 3 0 5 0 0 2 0 9
0 0 0 1 0 5 4 0 8
0 0 0 0 0 0 0 0 0
4 0 2 7 0 6 0 0 0
3 0 1 0 0 7 0 4 0
7 2 0 0 4 0 0 6 0
0 0 4 0 1 0 0 0 3
```

### 输出

```
2 4 5 9 8 1 3 7 6
1 6 9 2 7 3 5 8 4
8 3 7 5 6 4 2 1 9
9 7 6 1 2 5 4 3 8
5 1 3 4 9 8 6 2 7
4 8 2 7 3 6 9 5 1
3 9 1 6 5 7 8 4 2
7 2 8 3 4 9 1 6 5
6 5 4 8 1 2 7 9 3
```
