# 题目描述

在正整数集上定义如下的迭代序列：

- `n → n / 2`（若 `n` 为偶数）
- `n → 3n + 1`（若 `n` 为奇数）

从 10 开始应用上述规则，我们可以生成如下的序列：

`10 → 5 → 16 → 8 → 4 → 2 → 1`

可以看出这个序列（从 10 开始到 1 结束）共有 7 项。尽管还没有被证明，但我们普遍认为，从任何数开始最终都能迭代至 1。

给出多组询问，每组询问有一个正整数 `x`（`x ≤ 10^7`），你需要回答从 `x` 开始到 `1` 的序列的长度。

注：序列开始生成后允许其中的项超过 `10^7`。

## 输入描述

第一行一个正整数 `Q`，表示询问次数。

接下来 `Q` 行，每行一个正整数 `x_i`。

## 输出描述

对每个询问，输出以 `x_i` 开始到 `1` 的序列长度。

## 输入样例 #1

```
2
5
13
```

## 输出样例 #1

```
6
10
```

## 提示

- `1 ≤ Q ≤ 10^6`
- `1 ≤ x ≤ 10^7`

中间的计算结果可能会超过 `int` 类型，需要使用 `long long`。
