# 新4人传球游戏

## 题目描述

上体育课的时候，老师要求同学们 4 人一组练习传球。

假设有 A、B、C、D 四个人在练习传球，一开始球在 A 处。每次传球时，控球的人将球传给除自己以外的任意一个人。但是 B 不喜欢 A，于是球在 B 处时，一定不会传球给 A，也就是 B 只会传球给 C、D。

问传球 n 次后，球又回到 A 处的传球路线有多少种？

## 输入描述

1 行，1 个整数 n（2 ≤ n ≤ 40）。

## 输出描述

1 个整数，表示符合题意的方法数。

## 样例 1

**输入**

```text
3
```

**输出**

```text
4
```

## 样例说明

4 种路线是 ABCA、ABDA、ACDA、ADCA。
