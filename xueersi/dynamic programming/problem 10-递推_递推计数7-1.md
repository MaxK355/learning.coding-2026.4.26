# 递推计数7-1

## 题目描述

设 ABCDEF 为正六边形，一只青蛙开始在顶点 A 处，它每次可随意地跳到相邻两顶点之一。若跳完 n 次后：

1. 青蛙恰好停在 B 点，那么这只青蛙从开始到停止，可能出现的不同跳法共多少种？
2. 青蛙恰好停在 D 点，那么这只青蛙从开始到停止，可能出现的不同跳法共多少种？

## 输入描述

1 个正整数 n。

## 输出描述

- 第 1 行，输出 n 次后恰好停在 B 点的跳法数
- 第 2 行，输出 n 次后恰好停在 D 点的跳法数

## 样例 1

**输入**

```text
5
```

**输出**

```text
11
10
```

## 提示

1 ≤ n ≤ 30
