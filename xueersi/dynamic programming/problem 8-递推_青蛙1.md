# 青蛙1

## 题目描述

有 N 个石头，编号为 1, 2, ..., N。对于每个 i（1 ≤ i ≤ N），石头 i 的高度为 h_i。

最初有一只青蛙在石头 1 上。他将重复几次以下操作以到达石头 N：

- 如果青蛙当前在石头 i 上，则跳到石头 i+1 或石头 i+2。需要 |h_i − h_j| 的费用，而 j 是要落到上面的石头。

找到青蛙到达石头 N 时需要的最小总费用。

## 输入描述

- 第一行，包含一个整数 n，表示石头个数。
- 第二行，包含 n 个整数 h_1, h_2, …, h_n，表示每个石头的高度。

## 输出描述

一行一个整数，表示最小总费用。

## 样例 1

**输入**

```text
4
10 30 40 20
```

**输出**

```text
30
```

## 样例 2

**输入**

```text
2
10 10
```

**输出**

```text
0
```

## 样例 3

**输入**

```text
6
30 10 60 10 60 50
```

**输出**

```text
40
```

## 提示

**样例 1 解释**：跳跃顺序 1 → 2 → 4，花费的总费用最小为 |10 − 30| + |30 − 20| = 30。

**样例 2 解释**：跳跃顺序 1 → 2，花费的总费用最小为 |10 − 10| = 0。

**样例 3 解释**：跳跃顺序 1 → 3 → 5 → 6，花费的总费用最小为 |30 − 60| + |60 − 60| + |60 − 50| = 40。

对于 100% 的数据，2 ≤ n ≤ 10^5，1 ≤ h_i ≤ 10^4。
