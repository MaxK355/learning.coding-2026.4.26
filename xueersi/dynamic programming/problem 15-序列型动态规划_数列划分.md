# 数列划分

## 题目描述

给出 n 项的数列，要求将数列划分成若干段，且每一段之和都不超过 s。求一共有多少种满足要求的划分方法。

方法数很大，只要求输出除以 10^9 的余数。

## 输入描述

第 1 行，两个正整数 n, s。

第 2 行，n 个正整数 a[1], a[2], ⋯, a[n]。

## 输出描述

一个整数，划分方法数除以 10^9 的余数。

## 样例 1

**输入**

```text
5 3
1 2 1 1 1
```

**输出**

```text
10
```

## 提示

1 ≤ n ≤ 1000，1 ≤ a[i] ≤ 1000，1 ≤ s ≤ 10000。
