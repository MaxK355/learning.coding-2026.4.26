# 前缀和（模板）

## 题目描述

给出一个 n 个数组成的数组 a[1], a[2], ⋯, a[n]。你需要处理 Q 次询问，每次询问包含两个正整数 l, r（1 ≤ l ≤ r ≤ n），对每个询问，你需要回答和式 a[l] + a[l+1] + ⋯ + a[r] 的值。

## 输入描述

第 1 行，1 个正整数 n。

第 2 行，n 个整数 a[1], a[2], ⋯, a[n]，以空格分隔。

第 3 行，1 个正整数 Q。

接下来 Q 行，每行两个正整数 l, r。

## 输出描述

输出 Q 行，第 i 行输出第 i 次询问的答案。

## 样例 1

**输入**

```text
6
1 -6 5 -4 2 4
3
1 6
2 5
3 6
```

**输出**

```text
2
-3
7
```

## 提示

n, Q ≤ 10^5；−1000 ≤ a[i] ≤ 1000；1 ≤ l ≤ r ≤ n。
