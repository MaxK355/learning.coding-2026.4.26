# 阶段练习2：第K未被包含数

## 题目描述

给你一个数列 $a_1, a_2, \cdots, a_n$ 和 $Q$ 个询问。

第 $i$ 个询问给你一个正整数 $K_i$，你需要回答所有不等于 $a_1, a_2, \cdots, a_n$ 的正整数中，从小到大的第 $K_i$ 个数是什么。

## 输入描述

第 $1$ 行，两个正整数 $n, Q$。

第 $2$ 行，$n$ 个正整数 $a_1, a_2, \cdots, a_n$。

第 $3 \sim Q+2$ 行，每行一个正整数 $K_i$。

## 输出描述

输出 $Q$ 行，第 $i$ 行输出第 $i$ 个询问的答案。

## 样例 1

**输入**

```text
4 3
3 5 6 7
2
5
3
```

**输出**

```text
2
9
4
```

## 样例 2

**输入**

```text
5 2
1 2 3 4 5
10
100000000000
```

**输出**

```text
15
100000000005
```

## 提示

样例1：与 $3, 5, 6, 7$ 都不相等的正整数从小到大排列后是 $1, 2, 4, 8, 9, 10, \cdots$。第 $2$ 个数是 $2$；第 $5$ 个数是 $9$；第 $3$ 个数是 $4$。

样例2：答案可能超过 32 位整数类型范围。

对于 $30\%$ 的数据：$a_i \le 10^5$；$K_i \le 10^5$。

对于 $100\%$ 的数据：$1 \le n, Q \le 10^5$；$1 \le a_1 < a_2 < \cdots < a_n \le 10^{18}$；$1 \le K_i \le 10^{18}$。
