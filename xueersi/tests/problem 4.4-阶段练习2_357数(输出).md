# 阶段练习2：357数(输出)

## 题目描述

我们定义只由 $3$、$5$、$7$ 三种数码组成，相邻数码不同，且包含所有三种数码的正整数为 **357数**。

例如 $35757$ 是一个 357数；$3557$ 不是一个 357数，因为两个相同的数码相邻；$35353$ 不是一个 357数，因为只包含两种数码。

给出正整数 $n$，从小到大输出所有 $n$ 位的 357数。

## 输入描述

一个正整数 $n$。

## 输出描述

输出若干行，每行一个数，从小到大输出所有 $n$ 位的 357数。

## 样例 1

**输入**

```text
3
```

**输出**

```text
357
375
537
573
735
753
```

## 提示

对于 $100\%$ 的数据：$3 \le n \le 15$。
