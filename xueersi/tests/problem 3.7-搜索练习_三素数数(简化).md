# 3.7 搜索练习：三素数数（简化）

## 题目描述

如果一个数的所有连续三位数字都是大于 $100$ 的素数，则该数称为三素数数。比如 $113797$ 是一个 $6$ 位的三素数数。

现给定一个正整数 $n$，找到 $n$ 位数中，一共有多少个三素数数。

## 输入格式

输入共 $1$ 行：$1$ 个正整数 $n$。

## 输出格式

输出共 $1$ 行：第 $1$ 行，$1$ 个正整数，$n$ 位三素数数的个数。

## 样例 1

**输入**

```text
4
```

**输出**

```text
204
```

## 数据范围

$4 \le n \le 15$
