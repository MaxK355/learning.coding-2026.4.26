# 阶段练习2：数的划分

## 题目描述

将整数 $n$ 分成 $k$ 份，且每份不能为空，任意两个方案不相同（不考虑顺序）。

例如：$n=7$，$k=3$，下面三种分法被认为是相同的。

$$1,1,5; \quad 1,5,1; \quad 5,1,1.$$

问有多少种不同的分法。

## 输入描述

输入一行，两个正整数 $n$、$k$，其中 $6 < n \le 200$，$2 \le k \le 6$。

## 输出描述

输出一行，表示划分方法数。

## 样例 1

**输入**

```text
7 3
```

**输出**

```text
4
```

## 提示

四种分法为：

$$1,1,5; \quad 1,2,4; \quad 1,3,3; \quad 2,2,3.$$
