# 3.4 [ICPC 2022 Tehran R] 纸牌魔术

## 题目描述

Mahsa 已经练习洗牌好几个月了。今晚，她终于决定邀请朋友们过来，展示她的新技能。于是她拿起一副有 $2n$ 张牌的牌堆，在不改变牌堆顺序的情况下向朋友们展示了牌面，并请某人选择牌堆中的两个位置 $i$ 和 $j$。然后，她告诉大家，她将只通过应用两种洗牌方式，把第 $i$ 个位置的牌移动到第 $j$ 个位置。

假设牌堆中的牌为 $\langle c_1, c_2, \dots, c_{2n} \rangle$。Mahsa 可以任意多次执行以下两种洗牌：

- **Riffle（交错洗牌）**：将牌分成两部分 $\langle c_1, \dots, c_n \rangle$ 和 $\langle c_{n+1}, \dots, c_{2n} \rangle$，然后产生 $\langle c_1, c_{n+1}, c_2, c_{n+2}, \dots, c_n, c_{2n} \rangle$。
- **Scuffle（对调洗牌）**：从 $\langle c_1, c_2, \dots, c_{2n} \rangle$ 产生 $\langle c_2, c_1, c_4, c_3, \dots, c_{2n}, c_{2n-1} \rangle$。

请帮助 Mahsa 找出她需要的最少洗牌次数，剩下的部分她自己会搞定。

## 输入格式

输入包含一行，由三个空格分隔的整数 $n$、$i$ 和 $j$ 组成（$1 \le n \le 10^5$ 且 $1 \le i, j \le 2n$）。

## 输出格式

输出一个整数，表示将第 $i$ 张牌带到第 $j$ 个位置所需的最少洗牌次数。

## 样例 1

**输入**

```text
4 3 8
```

**输出**

```text
3
```

## 样例 2

**输入**

```text
5 4 1
```

**输出**

```text
5
```

## 样例 3

**输入**

```text
1 1 1
```

**输出**

```text
0
```
