# 阶段练习2：切木棍

## 题目描述

有 $n$ 根木棍，长度分别是 $a_1, a_2, \cdots, a_n$，可以最多切割 $k$ 次，每次切割只能将一根木棍切成两段整数长度的木棍。切割得到的木棍也可以再被切成两段。

在所有切割 $k$ 次的方法中，最长的一段木棍的长度最小可能有多短？

## 输入描述

第 $1$ 行，$2$ 个正整数 $n, k$。

第 $2$ 行，$n$ 个正整数 $a_1, a_2, \cdots, a_n$。

## 输出描述

$1$ 个整数，输出答案。

## 样例 1

**输入**

```text
2 3
7 9
```

**输出**

```text
4
```

## 样例 2

**输入**

```text
3 0
3 4 5
```

**输出**

```text
5
```

## 样例 3

**输入**

```text
10 10
158260522 877914575 602436426 24979445 861648772 623690081 433933447 476190629 262703497 211047202
```

**输出**

```text
292638192
```

## 提示

样例1：
先把长为 $7$ 的木棍切成长为 $3$、$4$ 的两段。
再把长为 $9$ 的木棍切成长为 $3$、$6$ 的两段。
最后把上次得到的长为 $6$ 的木棍切成 $3$、$3$ 两段。
此时最长的木棍的长为 $4$，是所有切割方法中，最长木棍最短的切法。

样例2：
也可能一次都不让切，那么初始木棍长度的最大值即为答案。

对于 $100\%$ 的数据：$1 \le n \le 2 \times 10^5$；$0 \le k \le 10^9$；$1 \le a_i \le 10^9$。
