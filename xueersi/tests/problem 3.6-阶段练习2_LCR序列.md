# 3.6 阶段练习 2：LCR 序列

## 题目描述

如果一个字符串仅由 `L`、`C`、`R` 三种大写字母组成，那么这个字符串就被称作是 LCR 序列。

小 A 现在想知道全部的长度为 $n$ 的 LCR 序列。

你需要按照字典序从小到大去输出这些序列。

## 输入格式

一行包含一个正整数 $n$。

## 输出格式

若干行。表示所有长度为 $n$ 的 LCR 序列，每行为一个仅由 LCR 组成的字符串。

## 样例 1

**输入**

```text
2
```

**输出**

```text
CC
CL
CR
LC
LL
LR
RC
RL
RR
```

## 数据范围

$1 \le n \le 12$
